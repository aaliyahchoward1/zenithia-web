# Zenithia — The World of Odd Orbit Beauty

A Space Baroque web family for [Odd Orbit Beauty](https://www.etsy.com/shop/OddOrbitBeauty): the realm behind the Renaissance Lipgloss Necklaces.

## The rooms

- **[Enter Zenithia](./map/)** — an interactive illuminated-atlas map of the realm. Ten golden hotspots open the locked district frames, each with a line of lore; the four shade districts link to the shop on Etsy. Lunuff, the realm's little alien bunny-puppy, keeps watch in the corner.
- **[Gallery at Zenith Nadir](./gallery/)** — the four shades exhibited as museum pieces with placards: Black Siren, Aquariosa, Nebula (this season: *Nebula's Gaze*), and Blood Moon. Real product photography only.
- **[The Zenithia Zine](./zine/)** — an eight-page page-flip booklet (StPageFlip) from cover to shop door.

## Tech

Plain HTML/CSS/JS — no build step, no dependencies beyond Google Fonts and the bundled StPageFlip library. Deploys anywhere static files live, including GitHub Pages.

## The world

Zenithia is the realm; Zenith Nadir is its central structure and the sacred origin site of the shades. Shade homes: Black Siren → Zenith Nadir · Aquariosa → the Moonlit Lake · Nebula → the Sky Market · Blood Moon → the Hollowlands.
